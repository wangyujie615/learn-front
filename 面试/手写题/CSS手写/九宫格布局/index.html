CSS九宫格布局实现

方法一：使用 Flexbox 实现九宫格布局

通过 flex-wrap: wrap 和 flex: 1 实现自适应的九宫格

CSS 代码：

.flex-grid {
    display: flex;
    flex-wrap: wrap;
    width: 500px;
    height: 500px;
    gap: 5px;
    background-color: #ddd;
    padding: 5px;
}

.flex-grid-item {
    flex: 1;
    min-width: calc(33.333% - 3.333px);
    height: calc(33.333% - 3.333px);
    display: flex;
    justify-content: center;
    align-items: center;
    background-color: #4ecdc4;
    color: white;
}

方法二：使用 CSS Grid 实现九宫格布局

通过 grid-template-columns 和 grid-template-rows 实现精确的九宫格

CSS 代码：

.css-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(3, 1fr);
    width: 500px;
    height: 500px;
    gap: 5px;
    background-color: #ddd;
    padding: 5px;
}

.css-grid-item {
    display: flex;
    justify-content: center;
    align-items: center;
    background-color: #ff6b6b;
    color: white;
}
