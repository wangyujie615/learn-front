Vue.js依赖收集演示

示例模板

<div id="app">
  <p>姓名：{{ name }}</p>
  <p>消息：{{ message }}</p>
  <p>完整信息：{{ greeting }}</p>
</div>

依赖收集流程

1. 模板编译阶段

编译器解析模板，识别插值表达式和指令：

// 编译第一个p标签 const exp = 'name'; // 提取表达式 this.bindText(node, exp); // 创建Watcher，进行依赖收集 // 编译第二个p标签 const exp = 'message'; // 提取表达式 this.bindText(node, exp); // 创建Watcher，进行依赖收集 // 编译第三个p标签 const exp = 'greeting'; // 提取表达式 this.bindText(node, exp); // 创建Watcher，进行依赖收集

2. 创建Watcher与依赖收集

为每个表达式创建Watcher实例，触发依赖收集：

function Watcher(vm, exp, cb) { this.vm = vm; this.exp = exp; this.cb = cb; // 关键步骤：将当前订阅者指向自己 Dep.target = this; // 访问数据，触发getter，进行依赖收集 this.value = this.get(); // 这里会触发数据的getter // 重置Dep.target Dep.target = null; }

3. 数据访问触发依赖收集

当访问数据属性时，触发getter，进行依赖收集：

Object.defineProperty(obj, key, { get() { // 关键：依赖收集 Dep.target && dep.addSub(Dep.target); return val; }, set(newVal) { if (newVal === val) return; val = newVal; observe(newVal); dep.notify(); // 通知更新 } });
