CSS水平垂直居中的实现方式

方法一：使用 Flex 布局实现水平垂直居中

Flex 水平垂直居中内容
.flex-container {
    display: flex;
    justify-content: center; /* 水平居中 */
    align-items: center; /* 垂直居中 */
}

方法二：使用定位 + transform 实现水平垂直居中

定位 + transform 居中内容
.position-container {
    position: relative;
}

.position-item {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}

方法三：使用定位 + margin: auto 实现水平垂直居中

定位 + margin: auto 居中内容
.position-container-2 {
    position: relative;
}

.position-item-2 {
    position: absolute;
    top: 0;
    left: 0;
    right: 0;
    bottom: 0;
    margin: auto;
    width: fit-content;
    height: fit-content;
}
