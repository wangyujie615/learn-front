**企业常用分片策略**

|分片策略|适用场景|优点|缺点|
|---|---|---|---|
|Hash（userId % N）|用户、订单|数据均匀|扩容困难|
|Range（按时间）|日志、订单|查询方便|热点明显|
|一致性Hash|分布式缓存|扩容影响小|实现复杂|
|按业务ID|多租户|简单|数据倾斜风险|

# 主从复制原理
1. Mater收到insert、update、delete数据, 写Binlog
2. Slave的IO线程连接Master询问是否有新的Binlog
3. Slave收到Binlog后保存Relay Log
4. SQL Thread读取Relay Log, 执行SQL, 保证数据的一致性
