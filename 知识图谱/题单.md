## 二、回溯算法

### 核心思想

回溯本质就是一个**增量构造答案**的过程，这个过程往往使用递归实现。

**回溯三问**：
1. 当前操作是什么？
2. 子问题是什么？
3. 下一个子问题是什么？

### 2.1 子集型回溯

两种模板：

**从输入的角度**：当前操作是当前的元素选/不选
```javascript
var subsets = function (nums) {
    const n = nums.length;
    const res = [];
    const path = [];
    const dfs = (i) => {
        if (i === n) {
            res.push(path.slice())
            return
        }
        dfs(i + 1)              // 当前元素不选
        path.push(nums[i])
        dfs(i + 1)              // 选择当前元素
        path.pop()              // 恢复现场
    }
    dfs(0)
    return res
};
```

**从结果的角度**：当前操作是枚举选哪个元素
```javascript
var subsets2 = function (nums) {
    const n = nums.length;
    const res = [];
    const dfs = (start, path) => {
        res.push(path.slice())
        for (let i = start; i < n; i++) {
            path.push(nums[i])
            dfs(i + 1, path)
            path.pop()
        }
    }
    dfs(0, [])
    return res
};
```

### 2.4 排列型回溯

```javascript
var permute = function (nums) {
    const res = [], path = []
    const visited = new Array(nums.length).fill(false)
    const dfs = () => {
        if (path.length === nums.length) {
            res.push(path.slice())
            return
        }
        for (let i = 0; i < nums.length; i++) {
            if (!visited[i]) {
                path.push(nums[i])
                visited[i] = true
                dfs(i + 1)
                visited[i] = false
                path.pop()
            }
        }
    }
    dfs()
    return res
};
```
